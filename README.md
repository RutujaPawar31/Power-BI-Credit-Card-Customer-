# Credit Card Customer Report Dashboard

## Project Overview
This project analyzes credit card customer transactions and revenue using Microsoft Power BI.

## Tools Used
- Power BI
- MySQL
- DAX
- Power Query

## Project Objectives
- Analyze total revenue.
- Calculate total transaction amount.
- Analyze interest earned.
- Understand customer transaction patterns.
- Compare card categories and customer segments.

## Dashboard KPIs
- Total Revenue
- Total Interest
- Income

## Dashboard Features
- Quarter-wise Analysis
- Gender-wise Analysis
- Card Category Analysis
- Weekly Transaction Trends
- Interactive Slicers

## Conclusion
This project helped me improve my skills in data analysis, SQL, data cleaning, DAX calculations, and Power BI dashboard development.
